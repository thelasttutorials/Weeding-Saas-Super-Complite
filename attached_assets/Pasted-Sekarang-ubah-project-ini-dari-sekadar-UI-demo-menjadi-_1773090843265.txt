Sekarang ubah project ini dari sekadar UI/demo menjadi aplikasi yang benar-benar aktif dan berjalan end-to-end.

Tujuan utama:
Saya ingin SEMUA fitur utama project ini benar-benar aktif, terhubung ke Supabase, dan bisa digunakan secara nyata, bukan hanya tampilan atau dummy state.

Jangan fokus pada dekorasi UI dulu.
Fokus utama adalah:
1. mengaktifkan semua flow utama
2. menghubungkan semua form ke Supabase
3. menghubungkan semua list/table ke data nyata
4. menambahkan role-based access
5. memastikan user app dan admin panel benar-benar berjalan

==================================================
FITUR YANG HARUS BENAR-BENAR AKTIF
==================================================

A. AUTHENTICATION
Aktifkan Supabase Auth secara nyata:
- register
- login
- logout
- session persistence
- proteksi route dashboard
- redirect setelah login
- forgot password flow UI-ready
- account info membaca user nyata

B. USER ROLE & ADMIN ROLE
Tambahkan sistem role:
- user biasa
- admin

Kebutuhan:
- simpan role user di profile/database
- route dashboard user hanya untuk user login
- route admin hanya untuk admin
- jika non-admin membuka admin page, redirect/forbidden
- navbar/sidebar menyesuaikan role

C. USER DASHBOARD
Aktifkan dashboard user secara nyata:
- overview stats membaca data nyata
- invitation list membaca data nyata
- create invitation aktif
- edit invitation aktif
- publish/unpublish aktif
- rsvp management aktif
- guest messages management aktif
- digital gift settings aktif
- gallery upload aktif
- account settings aktif

D. ADMIN PANEL
Aktifkan admin panel secara nyata:
- admin dashboard membaca data nyata platform
- users list membaca semua user
- invitations list membaca semua invitation
- subscriptions list membaca data nyata/placeholder realistis dari database
- platform stats membaca data nyata
- admin bisa melihat status user, role, plan, invitation count
- admin panel bukan dummy

E. INVITATION BUILDER
Aktifkan builder invitation:
- create invitation simpan ke database
- edit invitation ambil data dari database
- update semua section ke database
- validasi slug unik
- status draft/published aktif
- publish hanya jika data minimum valid

F. PUBLIC INVITATION PAGE
Aktifkan halaman publik:
- route /invite/[slug] membaca data nyata dari Supabase
- hanya status published yang bisa dibuka publik
- slug invalid menampilkan not found
- query param ?to=NamaTamu aktif
- semua section membaca data invitation nyata

G. RSVP SYSTEM
Aktifkan RSVP end-to-end:
- form RSVP submit ke database
- dashboard RSVP membaca data nyata
- statistik RSVP dihitung dari data nyata
- filter dan search bekerja

H. GUEST MESSAGE SYSTEM
Aktifkan ucapan tamu:
- form submit ke database
- daftar ucapan membaca data nyata
- hide/show message aktif
- moderation tersimpan ke database

I. DIGITAL GIFT SYSTEM
Aktifkan amplop digital:
- dashboard user dapat mengisi rekening bank
- dashboard user dapat mengisi e-wallet
- gift confirmation form submit ke database
- halaman publik membaca data nyata gift settings

J. GALLERY UPLOAD
Aktifkan upload galeri:
- upload ke Supabase Storage
- simpan URL/path ke database
- list gallery membaca data nyata
- delete image aktif
- reorder jika sudah ada UI-nya

K. ANALYTICS
Aktifkan analytics berbasis data nyata sebisa mungkin:
- total invitations
- total RSVP
- total messages
- total gift confirmations
- attendance rate

Jika invitation views belum ada tracking yang benar, jangan tampilkan angka palsu.
Gunakan fallback yang jujur.

L. SUBSCRIPTION / PLAN
Aktifkan struktur subscription:
- Free
- Premium
- Business

Kebutuhan minimal:
- simpan plan user di database
- dashboard membaca plan user
- admin bisa melihat plan user
- UI pricing terhubung ke data plan
- belum perlu payment gateway penuh, tapi struktur harus aktif dan nyata

M. WHITE LABEL
Jika white label sudah ada di UI:
- aktifkan simpan pengaturan white-label ke database
- brand name
- logo
- primary color
- hanya user Business yang bisa mengakses
