Buatkan aplikasi fullstack production-ready bernama "WedSaaS Admin" untuk platform undangan pernikahan digital. Gunakan stack: Next.js terbaru (App Router), TypeScript, Tailwind CSS, shadcn/ui, Prisma, PostgreSQL, NextAuth/Auth.js, Zod, TanStack Table, TanStack Query, dan Recharts. Struktur project harus rapi, scalable, reusable, dan benar-benar berfungsi end-to-end.

Konteks bisnis:
Website public WedSaaS adalah landing page SaaS undangan pernikahan digital dengan section:
- Hero
- Fitur
- Cara Kerja
- Tema
- Harga
- Testimoni
- FAQ
- CTA
- Footer

Saya ingin dibuatkan Admin Panel lengkap untuk mengelola semua isi landing page dan seluruh data bisnis platform.

Tujuan utama sistem admin:
1. Mengelola isi landing page
2. Mengelola paket harga
3. Mengelola tema undangan
4. Mengelola testimoni
5. Mengelola FAQ
6. Mengelola user/pelanggan
7. Mengelola undangan milik user
8. Mengelola pembayaran/subscription
9. Melihat dashboard statistik
10. Mengelola pengaturan website
11. Mengelola SEO
12. Mengelola role admin
13. Menyediakan autentikasi admin yang aman
14. Menyediakan audit log aksi admin

Role dan akses:
- SUPER_ADMIN: akses penuh semua fitur, kelola admin lain, kelola setting sensitif
- ADMIN: kelola konten, user, undangan, paket, tema, testimoni, FAQ, pembayaran, analytics
- EDITOR: hanya kelola konten landing page, testimoni, FAQ
Semua route admin harus dicek berdasarkan role.

Autentikasi:
- Buat halaman /admin/login
- Login email + password
- Password di-hash dengan bcrypt
- Gunakan NextAuth/Auth.js
- Jika belum login, semua route /admin/* redirect ke login
- Jika role tidak sesuai, tampilkan unauthorized page
- Sediakan logout
- Session harus aman
