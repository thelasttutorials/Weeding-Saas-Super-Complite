Tolong lanjutkan project WedSaaS yang sudah ada, jangan buat ulang dari nol.

Saya ingin kamu menambahkan dan mengaktifkan 15 fitur utama untuk SaaS undangan digital ini secara nyata, usable, dan terhubung ke flow aplikasi. Fokus pada implementasi yang benar-benar bisa dipakai, bukan sekadar UI dummy.

Tujuan utama:
- membuat WedSaaS lebih layak dijual sebagai platform undangan digital premium
- menambah fitur yang paling dicari user undangan digital
- memastikan semua fitur baru terhubung dengan invitation, dashboard user, halaman publik, dan admin jika relevan
- tetap menjaga UI clean, elegan, simpel, dan responsif di mobile, tablet, laptop, dan desktop

PENTING:
- gunakan codebase yang sudah ada
- refactor seperlunya
- jika ada fitur yang belum bisa full production, buat MVP yang jujur dan stabil
- jangan menampilkan data palsu seolah nyata
- semua tombol utama harus benar-benar punya action
- audit script dan perbaiki jika ada bagian yang bentrok

==================================================
FITUR 1 — AMPLOP DIGITAL / HADIAH ONLINE
==================================================

Aktifkan dan rapikan fitur amplop digital.

User harus bisa:
- menambahkan rekening bank
- menambahkan e-wallet
- menambahkan QRIS placeholder jika memungkinkan
- menyimpan data hadiah per invitation
- menampilkan hadiah di halaman public invitation
- tamu bisa klik copy nomor rekening / e-wallet
- tamu bisa submit konfirmasi hadiah

Admin/user dashboard harus bisa melihat:
- daftar gift confirmations
- nama pengirim
- nominal
- metode hadiah
- pesan
- status jika diperlukan

Field minimal:
- bank_name
- account_number
- account_holder
- wallet_name
- wallet_number
- qris_url optional
- sender_name
- amount
- method
- message

==================================================
FITUR 2 — FILTER UNDANGAN TAMU PER ACARA
==================================================

Tambahkan sistem event access per tamu.

Kebutuhan:
- satu invitation bisa punya beberapa acara:
  - akad
  - resepsi
  - ngunduh mantu
  - acara tambahan lainnya jika ada
- setiap tamu bisa di-assign ke acara tertentu saja
- halaman undangan publik hanya menampilkan acara yang relevan jika tamu dibuka lewat guest token/link unik
- jika tamu umum tanpa token, gunakan fallback event default

Dashboard user harus bisa:
- mengatur tamu diundang ke acara mana saja
- melihat assignment tamu ke acara
- edit assignment dengan mudah
