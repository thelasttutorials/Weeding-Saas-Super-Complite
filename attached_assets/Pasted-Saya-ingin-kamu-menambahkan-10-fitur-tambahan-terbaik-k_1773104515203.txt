Saya ingin kamu menambahkan 10 fitur tambahan terbaik ke project WedSaaS yang sudah ada.

PENTING:
- gunakan codebase yang sudah ada
- jangan bikin ulang dari nol
- refactor seperlunya
- setiap fitur harus usable, bukan sekadar UI
- jika ada bagian yang belum bisa full production, buat MVP yang jujur, stabil, dan mudah dikembangkan
- prioritaskan alur nyata, database flow, dan pengalaman pengguna

Tujuan utama:
meningkatkan WedSaaS menjadi SaaS undangan pernikahan digital yang lebih kuat, lebih premium, dan lebih lengkap.

==================================================
FITUR 1 — GUEST MANAGEMENT
==================================================

Tambahkan fitur manajemen tamu.

User harus bisa:
- melihat daftar tamu per invitation
- menambah tamu manual
- edit tamu
- hapus tamu
- cari tamu
- filter tamu
- kelompokkan tamu berdasarkan kategori

Kategori minimal:
- keluarga
- teman
- kantor
- VIP
- lainnya

Field tamu minimal:
- id
- invitation_id
- name
- phone optional
- email optional
- category
- guest_count
- notes
- custom_link_token / guest token
- invited_status
- rsvp_status
- checked_in_status
- created_at
- updated_at

Tambahkan halaman dashboard user:
- Guest Management
- Guest Import
- Guest Detail jika perlu

Tambahkan statistik kecil:
- total guests
- invited
- RSVP confirmed
- checked in

==================================================
FITUR 2 — PERSONALIZED GUEST LINK
==================================================

Tambahkan personalized guest link per tamu.

Contoh:
- /invite/ahmad-dan-sari?to=Budi
- /invite/ahmad-dan-sari?guest=token-unik

Kebutuhan:
- jika query to ada, tampilkan nama tamu di halaman invitation
- jika guest token ada, ambil nama tamu dari database
- tampilkan "Kepada Yth. Nama Tamu"
- jika guest token valid, RSVP harus terhubung ke tamu tersebut
- satu tamu bisa punya link unik

Dashboard user harus bisa:
- generate link tamu
- copy link tamu
- lihat status link sudah dibagikan atau belum jika ada field invited_status

==================================================
FITUR 3 — QR CHECK-IN TAMU
==================================================

Tambahkan fitur QR check-in tamu.

Kebutuhan:
- setiap tamu bisa punya QR code unik
- QR terkait ke guest token atau guest id
- dashboard user punya halaman Check-in
- user/petugas bisa scan QR tamu
- status checked_in diperbarui ke database
- tampilkan daftar tamu yang sudah check-in
- tampilkan statistik tamu hadir

Fitur minimal:
- generate QR per tamu
- halaman scanner/check-in sederhana
- fallback input manual jika scanner tidak tersedia
- check-in timestamp tersimpan

Tambahkan halaman:
- Guest Check-in
- Check-in History jika perlu

==================================================
FITUR 4 — CUSTOM MUSIC YANG LEBIH RAPI
==================================================

Rapikan dan perluas fitur custom music.

User harus bisa:
- upload file musik sendiri
atau
- memasukkan URL musik
- preview musik
- ganti musik
- hapus musik
- pilih apakah musik aktif untuk invitation
- pilih apakah music control ditampilkan

Jika autoplay dibatasi browser:
- tampilkan tombol play yang elegan
- jangan buat flow rusak

Simpan musik per invitation dan/atau per custom template jika arsitektur mendukung.

Tambahkan:
- volume default basic
- label lagu optional
- fallback jika file rusak/tidak ada

==================================================

Tambahkan media library untuk user.

User harus bisa:
- melihat semua aset media miliknya

- template list

FITUR 9 — COUPON / REFERRAL
==================================================

Tambahkan sistem kupon dan referral versi MVP.

A. Coupon

- membuat kupon
- menentukan tipe diskon:
  - percentage
  - fixed amount
- menentukan code
- menentukan aktif/tidak aktif
- menentukan masa berlaku
- menentukan maksimal penggunaan
- menentukan plan yang berlaku jika perlu

User harus bisa:

- membagikan referral code

- melihat reward placeholder/basic jika ada

Admin bisa:
- melihat referral usage
- melihat user yang mereferensikan

Jika reward automation belum siap:
- tetap simpan data referral usage ke database
- buat flow MVP yang jujur
