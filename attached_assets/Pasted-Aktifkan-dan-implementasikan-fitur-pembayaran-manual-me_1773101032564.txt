Aktifkan dan implementasikan fitur pembayaran manual menggunakan transfer bank untuk platform WedSaaS agar benar-benar berfungsi end-to-end.

Konteks:
Saat ini halaman langganan sudah memiliki paket Free, Premium, dan Business. Namun tombol pembayaran masih belum aktif dan hanya menampilkan info bahwa payment gateway segera hadir. Saya ingin sekarang tersedia metode pembayaran manual via transfer bank yang benar-benar dapat digunakan.

PENTING:
Jangan buat UI dummy. Jangan buat tombol palsu. Semua flow harus benar-benar bekerja, tersimpan ke database, memiliki status pembayaran, bukti transfer, verifikasi admin, dan aktivasi paket setelah pembayaran dikonfirmasi.

Gunakan stack yang sudah ada:
- Next.js App Router
- TypeScript
- TailwindCSS
- shadcn/ui
- Prisma ORM
- PostgreSQL
- NextAuth/Auth.js
- Zod
- React Hook Form
- TanStack Query

==================================================
TUJUAN FITUR
==================================================

User harus bisa:
1. memilih paket Premium atau Business
2. memilih metode pembayaran transfer bank
3. melihat instruksi transfer
4. mengunggah bukti transfer
5. mengirim pembayaran untuk diverifikasi admin
6. melihat status pembayaran
7. otomatis mendapatkan paket aktif setelah admin menyetujui pembayaran

Admin harus bisa:
1. melihat daftar pembayaran masuk
2. melihat bukti transfer
3. memverifikasi pembayaran
4. menolak pembayaran jika tidak valid
5. mengubah status pembayaran
6. mengaktifkan subscription user setelah pembayaran dikonfirmasi

==================================================
FLOW PEMBAYARAN YANG WAJIB BERJALAN
==================================================

Flow user:
1. User masuk ke halaman /dashboard/billing atau /dashboard/langganan
2. User klik "Pilih Premium" atau "Pilih Business"
3. Muncul modal / halaman checkout
4. User memilih metode "Transfer Bank"
5. Sistem membuat invoice pembayaran dengan status PENDING
6. Sistem menampilkan:
   - nomor invoice
   - nama paket
   - nominal transfer
   - rekening tujuan
   - nama bank
   - nama pemilik rekening
   - catatan transfer unik jika perlu
7. User transfer manual
8. User upload bukti transfer
9. Status pembayaran berubah menjadi WAITING_CONFIRMATION
10. Admin membuka panel pembayaran
11. Admin verifikasi bukti
12. Jika disetujui:
   - status payment jadi PAID
   - status subscription jadi ACTIVE
   - paket user berubah sesuai pembelian
13. Jika ditolak:
   - status payment jadi REJECTED
   - user diberi alasan penolakan
14. User bisa melihat riwayat pembayaran di dashboard

LOGIKA SUBSCRIPTION
==================================================

Aturan:

- Jika user membeli Premium dan disetujui:
  - subscription lama dinonaktifkan atau dianggap expired
  - buat subscription baru dengan plan Premium
- Jika user membeli Business dan disetujui:
  - update ke Business
- Jika pembayaran masih pending/rejected:
  - paket user jangan berubah
- Jika invoice kadaluarsa:
  - status jadi EXPIRED

Untuk masa aktif:
- Premium bisa one_time per invitation atau sesuai struktur plan saat ini
- Business bisa monthly
Sesuaikan dengan billingType plan yang sudah ada
