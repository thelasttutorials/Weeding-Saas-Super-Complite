Buatkan aplikasi SaaS production-ready bernama "WedSaaS" untuk platform undangan pernikahan digital menggunakan:

- Next.js terbaru dengan App Router
- TypeScript
- Tailwind CSS
- Supabase (Auth, Database, Storage)

Tujuan aplikasi:
User dapat membuat website undangan pernikahan digital yang elegan, membagikan link undangan, mengelola RSVP tamu, menerima ucapan, menampilkan amplop digital, dan melihat statistik undangan dari dashboard.

Arsitektur harus scalable dan multi-tenant sehingga satu user dapat memiliki banyak undangan.

==================================================
STRUKTUR APLIKASI
==================================================

Buat 4 area utama aplikasi:

1. Marketing Website
2. Authentication
3. User Dashboard
4. Admin Panel

Gunakan route group Next.js App Router:

/(auth)
/(dashboard)
/invite/[slug]
